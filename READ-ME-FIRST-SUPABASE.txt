THE EVERYTHING - مهم: خطوة واحدة داخل Supabase

عدّلت ملفات الموقع بحيث صور المجتمع تعرض:
- اسم المستخدم / اليوزرنيم
- صورة الحساب
- رابط يفتح مجموعة الصور الخاصة بصاحب المنشور

لكن المشكلة الظاهرة في صورتك ليست من HTML فقط. صفحة المجموعة كانت تستطيع قراءة المنشورات،
لكن بيانات profiles (الاسم والصورة) لم تكن متاحة للعامة أو قد يكون لبعض الحسابات القديمة صف profile مفقود.

لازم تسوي هذه الخطوة مرة واحدة:
1) افتح مشروعك في Supabase.
2) ادخل SQL Editor.
3) اختر New query.
4) افتح الملف الموجود مع الموقع: SUPABASE-COMMUNITY-FIX.sql
5) انسخ كل محتواه والصقه في SQL Editor ثم اضغط Run.
6) ارجع للموقع واعمل Refresh لصفحة wallpaper.html ثم افتح مجموعة أخوك.

الملف SQL يقوم بـ:
- السماح للزوار بقراءة بيانات البروفايل العامة المطلوبة للموقع.
- إبقاء تعديل البروفايل لصاحب الحساب فقط.
- إبقاء رفع/تعديل/حذف المنشور لصاحبه فقط.
- جعل صور avatars و wallpapers قابلة للعرض عبر الروابط العامة.
- إنشاء profile للحسابات القديمة التي ينقصها profile قدر الإمكان.
- إضافة إنشاء profile تلقائي للحسابات الجديدة.

ملاحظة أمنية:
الموقع يعامل جدول profiles كبيانات عامة. لا تضع فيه كلمة مرور أو معلومات سرية.
البريد وكلمة المرور تبقى داخل Supabase Auth ولا يتم عرضها للناس.
