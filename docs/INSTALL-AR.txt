إضافة خلفية صفحة البروفايل كاملة

1. افتح مشروع الموقع في Supabase ثم SQL Editor ثم New query.
2. انسخ محتوى PROFILE-PAGE-BACKGROUND.sql وشغّله مرة واحدة.
   هذا الملف يضيف جدولاً ومخزناً خاصين بخلفية الصفحة، ولا يغير خلفية البطاقة المحفوظة.
3. انسخ الملفات التالية إلى مجلد موقعك واستبدل الموجود منها:
   profile.html
   profile.css
   profile.js
   profile-cover.js
   profile-page-background.js
4. افتح البروفايل واضغط Ctrl+F5.
5. علامة + الجديدة تحت الشريط العلوي يميناً تخص خلفية الصفحة كاملة.
   علامة + الموجودة داخل بطاقة البروفايل تخص خلفية البطاقة فقط.
6. اختر JPG أو PNG حتى 5 MB، ثم راجع المعاينة واضغط Save background.
   Remove background يحذف الخلفية المختارة فقط دون التأثير على الخلفية الأخرى.

يتم قص الصورة من الوسط إلى 1600×900 وحفظها كصورة JPEG ثابتة. GIF غير مقبول.
خلفية الصفحة تظهر خلف المحتوى مع تغميق يحافظ على القراءة؛ البطاقات والهيدر تحتفظ بتصميمها.
احتفظ بملفات الموقع المشتركة، ومنها back-navigation.js وsite-shell.js وsite-branding.css.
لا حاجة لإعادة تشغيل SQL الخاص بخلفية البطاقة إذا سبق إعداده.
تم اختبار استقلال الحفظ والحذف ورفض GIF والتعامل مع فشل الحفظ بمحاكاة Supabase.
لم يتم تنفيذ SQL في مشروعك أو اختبار الرفع الفعلي بحسابك أو العرض في متصفح رسومي.
