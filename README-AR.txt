لوحة إدارة The Everything
========================
حساب الأدمن الوحيد:
fbd26b81-914b-4420-9a0d-f43c84c0abdf
الصلاحية مرتبطة بالحساب؛ يمكنك الدخول من أي جهاز. لا تعتمد على اسم المستخدم أو الجهاز.

التركيب بالترتيب
1. احتفظ بنسخة احتياطية من ملفات موقعك وقاعدة بياناتك.
2. افتح مشروع Supabase الحالي ثم SQL Editor ثم New query.
3. انسخ محتوى ADMIN-SETUP.sql كاملًا وشغّله مرة واحدة.
   الملف ينشئ جدول الأنمي وصلاحيات الإدارة وحاوية أغلفة الأنمي.
   يتطلب وجود جدول wallpapers الحالي وحاوية wallpapers.
   لا يمسح خلفيات المستخدمين أو بيانات حساباتهم. DROP POLICY داخل الملف يخص السياسات التي يضيفها هذا التحديث فقط.
4. انسخ ملفات HTML وJS وCSS الموجودة في الحزمة إلى مجلد الموقع نفسه واستبدل الملفات المتطابقة.
   هذه حزمة تحديث فقط: لا تحذف ملفات الموقع الأخرى أو مجلد image أو videos.
   لا تحتاج رفع README أو SQL إلى الموقع.
5. افتح الموقع عبر استضافتك وسجّل الدخول بالحساب صاحب المعرّف أعلاه، ثم حدّث الصفحة مع تجاوز الكاش Ctrl+Shift+R.
6. افتح Admin Panel من قائمة الحساب في الرئيسية أو صفحة الأنمي، أو افتح admin.html مباشرة.
   عند بقاء ملفات قديمة في المتصفح امسح كاش الموقع/الاستضافة.

الاستخدام
- أضف اسم الأنمي ومعرّفًا إنجليزيًا فريدًا مثل one-piece.
- اختر صورة JPG/PNG/WebP حتى 5 MB، أو استخدم رابط صورة أو مسارها الحالي.
- أدخل عدد الحلقات، ثم روابطها بهذا الشكل، كل حلقة في سطر:
1 | https://example.com/episode-1.mp4
2 | https://example.com/episode-2.mp4
- الفيديو المباشر وروابط تضمين Bunny مدعومة. بقية الروابط تفتح كمصدر خارجي.
- لا تكتب سطرًا لحلقة ليس لها رابط؛ ستظهر غير متوفرة عند فتحها.
- تعديل وحذف الأنميات من القائمة. التغييرات تظهر للزائر عند فتح الصفحة أو تحديثها.
- من قسم خلفيات المستخدمين تستطيع البحث وحذف خلفيات أي مستخدم بعد التأكيد.
- الحذف يزيل سجل الخلفية ثم ملفها من التخزين. إذا فشل تنظيف الملف يظهر زر إعادة المحاولة؛ استخدمه قبل إغلاق الصفحة.
- حذف الأنمي يزيل بياناته وروابطه فقط، ولا يحذف الفيديوهات الخارجية. صور الأغلفة المرفوعة القديمة تبقى في anime-posters ويمكن تنظيفها لاحقًا من Supabase Storage بعد التأكد أنها غير مستخدمة.

الأنمي الموجود
تم تضمين Attack on Titan وصورته المحلية ورابط الحلقة الأولى الموجود في موقعك.
بقية الحلقات بلا روابط حتى تضيفها. أصبح Supabase مصدر قائمة الأنمي بدل تعديل anime-data.js يدويًا.
إعادة تشغيل SQL بعد حذف الأنمي التجريبي ستضيف Attack on Titan مجددًا إن لم يكن موجودًا.

التحقق بعد التركيب
- حساب الأدمن: جرّب إضافة أنمي تجريبي وتعديله وحذفه، وحذف خلفية تجريبية.
- حساب عادي وزائر: افتح admin.html؛ يجب ألا تظهر أدوات الإدارة.
- صلاحيات قاعدة البيانات تتحقق من auth.uid()؛ إظهار أزرار الإدارة يدويًا لا يمنح صلاحية.
- إذا ظهر خطأ RLS أثناء حذف خلفية، أرسل رسالة الخطأ والسياسات الحالية؛ قد توجد سياسة restrictive قديمة تمنع الإجراء.

حدود التحقق
تم فحص صياغة JavaScript والسكربتات داخل HTML ومحاكاة دخول الأدمن/المستخدم/الزائر وتحميل الأنمي بحالات النجاح والفراغ والخطأ.
لم يتم تشغيل SQL على مشروعك أو اختبار عمليات حقيقية على Supabase، ولم تُحذف أي بيانات من حسابك.
لا توجد مفاتيح service_role في الملفات؛ المفتاح الموجود هو مفتاح النشر العام للموقع.
