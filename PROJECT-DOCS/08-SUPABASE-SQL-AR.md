# تعليمات SQL وSupabase

- **لا يوجد SQL جديد مطلوب لتحديث دمج ملفات Episode Guides.** لا حاجة لتشغيل أي ملف SQL لتطبيق هذا التعديل.
- ملفات SQL القديمة موجودة في `docs/` و`deatals/` وفي جذر المشروع من تحديثات سابقة. لا تُشغّلها كلها معًا؛ راجع جداول الإنتاج والسياسات والبيانات الحالية أولًا.
- أي تطوير مستقبلي يحتاج تعديلات schema يُكتب في ملف SQL منفصل (مثل `PROJECT-DOCS/SQL/<feature>.sql`) مع شرح الهدف والمخاطر وخطة الرجوع، ويُسلّم للمالك لمراجعته وتنفيذه.
- لا تُدرج أسرار Supabase، ولا `service_role` في JS عام أو الوثائق. RLS ينبغي أن يقيد بيانات نشاط الحلقات للمستخدم صاحبها فقط.
