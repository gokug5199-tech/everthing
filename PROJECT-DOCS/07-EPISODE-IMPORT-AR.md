# استيراد روابط الحلقات ومرجع One Piece

## الشكل المطلوب عند تقديم روابط للمالك
```
108 | VOE | https://voe.sx/example1
109 | VOE | https://voe.sx/example2
```
(المثال مجرد صيغة، وليس روابط حقيقية.)

- اقرأ رقم الحلقة من اسم ملف مثل `Anime_Rift_One_Piece_108.0_ar_sub_1794399149339.mp4`، ورتب رقمياً تصاعدياً، ولا تعِد الترقيم من 1.
- افصل الأنميات والمواسم المختلفة. اكتشف الناقص والمكرر والبدائل. قدم نصًا كاملًا يمكن نسخه مرة واحدة.
- الرابط الخارجي مثل `https://voe.sx/ID` ليس `mp4` مباشرًا؛ لا تُنشئ رابط تنزيل خيالي.
- إرسال الروابط في محادثة **لا يحفظها في Supabase**؛ يحتاج تشغيل إجراءات الرفع الفعلية أو إدخال المالك بنفسه.
