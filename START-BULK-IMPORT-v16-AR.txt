THE EVERYTHING — BULK 500 ANIME / v16
======================================

هذه حزمة تحديث حقيقية لملفات موقعك المرفوعة في all.zip.
كل أزرار ورسائل الموقع باللغة الإنجليزية. هذه التعليمات بالعربية فقط.

الخطوة 1 — نسخة احتياطية
احفظ نسخة من ملفات موقعك وقاعدة بيانات Supabase قبل تطبيق التحديث.

الخطوة 2 — Supabase (مطلوب مرة واحدة)
افتح Supabase Dashboard > SQL Editor.
انسخ محتويات الملف BULK-ANIME-SETUP-v16.sql ونفّذها باستخدام صلاحيات مشروعك.
الملف يضيف mal_id و anime_type و mal_relations إلى site_anime،
مع قيد فريد يمنع تكرار MAL ID ودالة آمنة لتنظيم الأجزاء.
لا يحذف أي أنمي أو حلقات أو صور موجودة.

الخطوة 3 — ملفات موقعك
افتح مجلد all الموجود داخل ZIP.
انسخ محتوياته إلى المجلد الذي يحتوي على admin.html و index.html في موقعك.
استبدل الملفات المتماثلة بعد أخذ نسخة احتياطية.
لا تحذف مجلد image أو icons أو صورك الأصلية.
إذا استخدمت حزمة PATCH، فانسخ الملفات المحددة فقط؛ الحزمة الكاملة CODE
تحتوي على ملفات all.zip كلها بعد التعديل، لكنها لا تشمل مجلد صور الموقع.

الخطوة 4 — تشغيل الاستيراد
انشر الموقع، سجّل الدخول بحساب Admin، ثم افتح admin.html > Anime.
ستجد لوحة Bulk Catalog Import في أعلى منطقة إدارة الأنمي.
اضغط Check Connection & Database أولًا.
بعد نجاح الفحص اضغط Import 500 New Anime مرة واحدة.
ابقِ الصفحة مفتوحة أثناء الاستيراد؛ يمكن أن يستغرق عدة دقائق
لأن API يعيد معلومات وعلاقات كل أنمي على حدة، ويحترم حدود الطلبات.
يمكن الضغط على Pause safely ثم Resume Import من نفس المتصفح.
إذا أغلقته فجأة، افتح الأدمن من المتصفح نفسه واضغط Resume Import.
لا تفتح الاستيراد في علامتي تبويب في الوقت نفسه.

كيف يعمل؟
- الهدف 500 أنمي NEW، وليس 500 نتيجة إجمالية.
- يبدأ بمقارنة الأنميات الموجودة فعلًا في قاعدة البيانات (مثل 58 الحالية).
- يقارن MAL ID والأسماء البديلة، ويمنع SQL تكرار MAL ID بعد التحديث.
- يختار عناوين من صفحات عشوائية ضمن نطاق كبير من كتالوج Tenrai،
  ويعطي أولوية لبعض الأجزاء والنسخ المرتبطة ضمن حد 500.
- يجلب الملصق والعنوان والوصف والتصنيف والعمر والاستوديو والموسم والسنة،
  ويحفظ روابط Prequel / Sequel / Side Story / Remake / Alternative.
- يربط الأعمال التي أصبحت موجودة في مكتبة موقعك بروابط داخلية.
  غير الموجودة تظهر كرابط إلى MyAnimeList (بدل صفحة مكسورة).
- ينظم سلاسل prequel/sequel المتصلة الموجودة في كتالوجك بناءً على بيانات المصدر،
  ويترك ترتيب الحكايات الغامضة/الموازية غير محدد بدل اختراع ترتيب.
- لا يغيّر معلومات الأنميات الحالية، ولا يستورد ملفات حلقات أو فيديو.
- الشخصيات غير مستوردة في دفعة الـ500 لتفادي آلاف الطلبات الثقيلة.
- صفحة الأدمن تعرض أول 60 سجلًا ثم Show more لتخفيف بطء الجوال.

ملاحظات مهمة
- الأنميات الـ58 القديمة لا تملك MAL ID بالضرورة. مقارنة الأسماء البديلة
  تقلل التكرار، لكنها لا تستطيع ضمان التطابق إذا الاسم القديم مختلف تمامًا.
  أضف MyAnimeList ID اختياريًا في تحرير تلك الأنميات إذا أردت مطابقة مضمونة.
- زر الاستيراد لا يعمل حتى تنفّذ ملف SQL.
- لا يمكن ضمان 500 مكتملة إن كان Tenrai متوقفًا أو البيانات غير كافية؛
  ستحفظ الأنميات المضافة بالفعل ويمكنك استكمال العملية لاحقًا.
- صور الملصقات روابط خارجية وليست نسخًا مخزّنة في Supabase.
  تأكد من امتلاك حق عرض الصور قبل النشر النهائي.
- لم يُشغّل استيراد حقيقي ضد Supabase الخاص بك؛ الاختبارات محاكاة محلية.
