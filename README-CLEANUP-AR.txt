THE EVERYTHING — CLEAN PROJECT (OCTOBER 2026)
================================================
هذه نسخة من ملفات test.zip بعد مراجعة التكرارات والمراجع الفعلية في ملفات HTML وCSS وJS.

اختيار الحزمة:
- Full ZIP: مشروع نظيف مكتمل بجميع الصور والأيقونات، مناسب لفكّه في مجلد جديد.
- CODE ZIP: بدون الصور والأيقونات، مناسب للتحديث فوق مشروعك الحالي فقط؛ يجب إبقاء image وicons كما هما.
  نسخ CODE فوق المجلد القديم لن يحذف الملفات الزائدة تلقائيًا؛ راجع OLD-FILES-TO-REMOVE-AR.txt.

التثبيت:
1. خذ نسخة احتياطية من موقعك الحالي.
2. الأفضل فك ZIP في مجلد جديد، وليس دمجه فوق مجلد قديم إذا أردت إزالة الملفات الزائدة.
3. ارفع محتويات the-everything إلى استضافتك، مع الحفاظ على مجلد image كاملًا.
4. شغّل الموقع عبر Live Server محليًا للتأكد قبل النشر.
5. عند النشر، حدث كاش الصفحة والتطبيق المثبّت (تم تحديث رقم كاش Service Worker).
6. لا تُشغّل ملفات SQL القديمة مرة أخرى لمجرد تنظيف ملفات الموقع؛ بيانات Supabase لم تتغير.

التحسينات:

- إخراج ملفات التنسيق والسكريبتات القديمة غير المشار إليها في الموقع.
- جمع anime-v6.css و anime-v7-fixes.css في anime.css، وترتيب القواعد محفوظ تمامًا.
- جمع anime-v6.js و anime-carousel-v7.js في anime-page.js، وترتيب التشغيل محفوظ.
- تحديث روابط anime.html وكاش service-worker.js لهذا الدمج.
- ربط wallpaper-v7-fixes.css الذي كان موجودًا ولكنه لم يكن يعمل في الصفحة.
- تجميع ملفات README التاريخية في النسخة الاحتياطية. هذا الملف هو دليل هذه الحزمة.

مهم:
- ملفات te-v5.css وshared-header-v6.css وغيرها ليست نسخًا مكررة: ما زالت صفحات الموقع تستخدمها.
- الصور الكبيرة وملفات الخلفيات بقيت كما هي، حتى لو كان اسم بعضها فيه امتدادان مثل .jpg.jpg.
- لا تحذف شيئًا من بيانات Supabase؛ هذه العملية على ملفات موقعك المحلية فقط.
- لا ترفع مجلد docs إلى مجلد ويب عام إذا لا تحتاج ظهوره للزوار؛ هو خاص بإعداد قاعدة البيانات.
- مجلد legacy موجود في ZIP احتياطي منفصل للرجوع إلى الملفات القديمة إذا لزم.
