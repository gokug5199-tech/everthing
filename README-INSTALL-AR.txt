The Everything — Home Rebuild v4
================================

هذا تحديث الصفحة الرئيسية فقط. يعمل على الكمبيوتر والجوال.

طريقة التركيب:
1) خذ نسخة احتياطية من index.html الحالي.
2) فك ملف ZIP.
3) انسخ جميع الملفات والمجلدات الموجودة بجانب هذا الملف إلى المجلد الرئيسي لموقعك، حيث توجد anime.html و wallpaper.html.
4) وافق على استبدال index.html و manifest.webmanifest و service-worker.js.
5) لا تحذف مجلد الصور القديم في موقعك. مجلد image/home جديد ويُضاف إليه فقط.
6) جرّب عبر VS Code Live Server قبل النشر. بعد النشر اضغط Ctrl+F5 على الكمبيوتر؛ إذا ثبت الموقع كتطبيق فأغلق التطبيق ثم افتحه، وإن احتجت حدّث كاش المتصفح.

محتويات التحديث:
- index.html: تصميم رئيسية جديد بالكامل للجوال والكمبيوتر.
- home-2026.css: تنسيقات التصميم الجديد.
- home-2026.js: تحسينات بسيطة للتفاعل.
- home-auth.js: كود الحساب والأدمن مأخوذ من index.html القديم ومحفوظ كما هو وظيفيًا.
- image/home/: صور محسّنة من صور موقعك وشعار The Everything.
- icons/: شعار التطبيق الأصلي بحجم 192 و512.
- manifest.webmanifest و service-worker.js: تحديث هوية الـPWA والكاش.

ملاحظات مهمة:
- Latest Anime و Latest Episodes يظلان داخل anime.html فقط؛ لم تُضاف الأقسام إلى الرئيسية.
- Anime و Wallpapers روابط فعالة، Films مذكورة كـComing Soon.
- لا تغييرات على Supabase أو صفحات الأنمي أو الحلقات أو لوحة الأدمن.
- راجع شكل التصميم بعد تحميله على استضافتك باستخدام HTTPS، لأن اختبار التصفح الكامل مع Supabase يحتاج البيئة الحقيقية.
