تحديث مواعيد عرض الأنمي

هذه الحزمة تشمل تحديث مكتبة الأنمي السابق بالإضافة إلى مواعيد العرض.

1. إذا لم تركب تحديث مكتبة الأنمي السابق، شغّل ANIME-LIBRARY-SETUP.sql أولاً.
2. شغّل ANIME-SCHEDULE-SETUP.sql كاملاً في Supabase > SQL Editor.
3. انسخ ملفات HTML وJS وCSS المرفقة إلى مجلد موقعك واستبدل المتطابق، ثم انشر الموقع.
   لا تحذف بقية الملفات أو مجلد الصور؛ هذه حزمة تحديث وليست الموقع كاملاً.
4. حدّث الصفحة تحديثاً كاملاً لتجنب النسخة القديمة المحفوظة في المتصفح.

من Admin > Anime > Edit ستجد Release schedule:
- Release season: Winter / Spring / Summer / Fall.
- Release year: سنة العرض، مثال 2026.
- Start date: تاريخ بداية العرض.
- End date: تاريخ نهاية العرض؛ اتركه فارغاً إذا لم يُعلن.
- New episodes on: يوم نزول الحلقة من Monday إلى Sunday.
احفظ الأنمي، وستظهر المعلومات في تفاصيله باللغة الإنجليزية.

جميع هذه المعلومات اختيارية وتُدخل يدوياً. المعلومات غير المحددة تظهر Not announced.
موسم العرض مثل Fall مختلف عن ترتيب المواسم Season 1 / Season 2.
تاريخ النهاية لا يجوز أن يسبق تاريخ البداية. لا نغير حالة العرض تلقائياً بناء على التاريخ.
عند اختيار Airing status = Completed يظهر Released on بدلاً من Every ليوم العرض.

اختُبرت الحقول وحفظ القيم وعرضها محلياً، وكذلك SQL وإعادة تشغيله.
لم يُشغّل SQL على مشروع Supabase الخاص بك؛ شغّله حسب الخطوات أعلاه.
