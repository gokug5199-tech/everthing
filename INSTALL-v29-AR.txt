The Everything v29 — Fast Admin (Cloudflare Pages + GitHub)
===========================================================
طريقة تركيب PATCH:
1. فك ضغط PATCH v29.
2. انسخ admin.html وadmin.js وadmin.css وbulk-anime-v16.js إلى جذر مستودع GitHub الخاص بموقعك.
3. وافق على استبدال الملفات الأربعة، ثم Commit changes.
4. انتظر اكتمال النشر في Cloudflare Pages، ثم حدّث لوحة Admin بتحديث قوي (Ctrl+Shift+R).

ما تغيّر:
- Admin Anime يطلب 48 سجلًا صغيرًا فقط عند الفتح ويستخدم البحث والصفحات من Supabase.
- عند الضغط Edit يتم جلب سجل الأنمي كاملًا (الشخصيات، العلاقات، الوصف) لمرة واحدة.
- تبويب Episodes يجلب فهرس العناوين فقط عند فتحه.
- استيراد 500 يحمل الفهرس الكامل اللازم لمنع التكرار وترتيب الأجزاء عند بدء الاستيراد، وليس عند فتح Admin.
- اقتراحات Series key تُحمل عند استخدام الخانة فقط.
- يتم الاحتفاظ بنص Google AdSense في جميع الصفحات، ولا حاجة إلى SQL.

الاختبار: فحص صياغة JavaScript واختبار محلي بمحاكاة Supabase لـ4500 أنمي.
لم يتم اختبار قاعدة بيانات الإنتاج أو الأداء الحقيقي على موقعك بعد النشر.
